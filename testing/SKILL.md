name: testing
description: This skill is for reviewing and generating code coverage reports, and for writing unit tests.
---

Use this skill to review and generate code coverage reports, and to write unit tests.

1. Review the UI markup and determine which user interactable elements are present.
2. For each interactable element, determine if there are any existing unit tests that cover it.
3. If there are existing unit tests, review them to ensure they are comprehensive and cover all edge cases.
4. If there are no existing unit tests, or if the existing tests are insufficient, write new unit tests to cover the interactable elements and their expected behaviors.
5. Generate a code coverage report to identify any areas of the codebase that are not adequately tested, and prioritize writing tests for those areas to improve overall code quality and reliability.
6. Continuously update and maintain the unit tests as the codebase evolves, ensuring that new features and changes are properly tested to prevent regressions and maintain high code quality.
7. Suggest improvements to the testing strategy, such as adopting new testing frameworks, implementing automated testing pipelines, or increasing test coverage in critical areas of the codebase.
8. Suggest mutation testing to identify weaknesses in the existing test suite and improve its effectiveness in catching potential bugs and issues in the codebase.
9. Suggest UI improvements based on the testing results, such as adding error messages, improving user feedback, or enhancing the overall user experience to make it more intuitive and user-friendly.
10. Ensure that changes to code are covered in relevant unit tests, and that the tests are updated to reflect any changes in functionality or behavior. This helps maintain the integrity of the codebase and ensures that new features or modifications do not introduce unintended bugs or issues.
